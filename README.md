# Dott Jeans Website (Odoo 19)

This project is an e-commerce website called **Dott Jeans**, built using **Odoo 19**.  
It provides an online store experience with product browsing, shopping features, and a complete backend system.

We learned a lot about **Odoo 19**, including its backend structure, modules, and how to build and customize business applications.

---

## Website Link

The project is deployed here:

https://edu-dottjeans.odoo.com/

⚠️ Note: This website is temporary.  
It has an expiration date of **1 year** and will stop after that.
